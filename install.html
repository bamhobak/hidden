🌰 히든 플러스 설치 안내

네이버 블로그 숨김 텍스트 삽입 + 텍스트 수식 변환기

현재 버전 v1.0.9.29

PC마다 한 번씩만 하면 됩니다.

1

예전 것 지우기

  1. 크롬 오른쪽 위 텀퍼몽키 아이콘 → 대시보드
  2. 목록에서 Bamhobak new hidden+ 찾기
  3. 오른쪽 끝 휴지통 아이콘을 눌러 삭제
2

새로 설치하기

https://bamhobak.github.io/hidden/hidden-plus.user.js
  1. 위 주소를 복사해 주소창에 붙여넣고 엔터
  2. 왼쪽 위 설치 버튼 누르기
  3. 혹시 다운그레이드 버튼이 나오면 그것을 누르면 됩니다
3

업데이트 주기 바꾸기

  1. 텀퍼몽키 대시보드 → 위쪽 설정 탭
  2. 아래쪽 스크립트 업데이트 칸에서
  3. 확인 주기를 매일 → 6시간으로 변경
