🌰 히든 플러스 설치 안내

네이버 블로그 숨김 텍스트 삽입 + 텍스트 수식 변환기

현재 버전 v1.0.9.23

PC마다 한 번씩만 하면 됩니다. 아래 4단계를 순서대로 따라 하세요. 한 번 깔아 두면 새 버전은 알아서 들어옵니다.

1

예전 것 지우기

  1. 크롬 오른쪽 위 텀퍼몽키 아이콘 클릭 → 대시보드
  2. 목록에서 Bamhobak new hidden+ 찾기
  3. 오른쪽 끝 휴지통 아이콘을 눌러 삭제

지우지 않고 새로 깔면 같은 것이 두 개 돌 수 있습니다. 꼭 먼저 지워 주세요.

2

새로 설치하기

아래 주소를 복사해서 주소창에 붙여넣고 엔터를 누르세요.

https://bamhobak.github.io/hidden/hidden-plus.user.js

텀퍼몽키 설치 화면이 뜨면 왼쪽 위 설치 버튼을 누릅니다. 코드를 복사해 붙여넣을 필요는 없습니다.

3

업데이트 확인 주기 바꾸기

기본값이 하루 한 번이라 새 버전이 늦게 들어옵니다. 6시간으로 줄여 둡니다.

  1. 텀퍼몽키 대시보드 → 위쪽 설정 탭
  2. 아래쪽 스크립트 업데이트 칸을 찾습니다
  3. 확인 주기를 매일 에서 6시간으로 바꿉니다
  4. 바로 저장됩니다 (위에 "작업이 성공적으로 완료됨" 이라고 뜹니다)

헷갈리기 쉬운 곳 — 맨 아래 외부 칸에도 업데이트 주기가 있는데 그건 다른 항목입니다. 외부는 안 함 그대로 두고, 반드시 스크립트 업데이트 칸의 확인 주기를 바꾸세요.

설정 모드는 초보자 그대로 둬도 보입니다.

4

잘 깔렸는지 보기

  1. 네이버 블로그에서 글쓰기 화면을 엽니다
  2. 오른쪽에 떠 있는 초록색 변환 버튼을 마우스 오른쪽 클릭
  3. 옵션창 맨 왼쪽에 버전 번호가 보이면 성공입니다

글을 하나 열어서 제목 옆에 🌰 히든 실행 버튼이 보이는지도 같이 확인하면 좋습니다.

이런 게 뜬다면

"주의! 유저 스크립트 다운그레이드" 가 떠요

예전 스크립트의 버전이 날짜(2026-10-19)로 되어 있어서, 텀퍼몽키가 숫자로 비교하다가 새 버전을 더 낮다고 착각하는 것입니다.

취소를 누르고 1단계 삭제부터 다시 하시면 경고 없이 깔립니다. 그냥 다운그레이드를 눌러도 설치는 되지만, 지우고 까는 쪽이 깔끔합니다.

한 번 지우고 깔면 다음부터는 이 경고가 안 뜹니다.

설치 화면이 안 뜨고 코드만 보여요

크롬 확장 프로그램 페이지(chrome://extensions)에서 오른쪽 위 개발자 모드가 켜져 있는지 확인해 주세요.

지금 깔린 버전이 몇인지 보고 싶어요
  • 텀퍼몽키 대시보드 → 설치된 유저 스크립트 목록에서 이름 옆 버전
  • 또는 글쓰기 화면에서 변환 버튼 우클릭 → 옵션창 맨 왼쪽

지금 당장 새 버전을 받고 싶을 때

방법 1 — 설치 주소를 다시 열기 (가장 확실)

주소창에 아래를 다시 입력하면, 새 버전이 있을 때 업데이트 버튼이 있는 화면이 뜹니다.

https://bamhobak.github.io/hidden/hidden-plus.user.js

새 버전이 없으면 이미 설치되어 있다는 안내만 나오니, 눌러봐도 손해는 없습니다. 이 방법은 설정 모드나 메뉴 위치와 상관없이 항상 됩니다.

방법 2 — 유틸리티 탭에서 한 번에 확인

텀퍼몽키 대시보드 → 위쪽 유틸리티 탭 → 업데이트 확인 버튼. 깔려 있는 스크립트 전부를 한 번에 확인합니다.

방법 3 — 목록에서 그 스크립트만 확인

설치된 유저 스크립트 탭에서 Bamhobak new hidden+ 줄의 마지막 업데이트 날짜를 클릭합니다. 설정 모드가 초보자면 이 칸이 안 보일 수 있는데, 그럴 땐 방법 1이나 2로 하세요.
